# E-Bazaar

A modern e-commerce platform built with Next.js, allowing users to browse products, manage stores, and handle online shopping operations.

## Features

- User authentication
- Product browsing and management
- Store creation and management
- Shopping cart functionality
- Order management
- Admin dashboard
- Store dashboard
- Product and coupon management
- Address management
- Responsive UI

## Tech Stack

### Frontend
- Next.js
- React
- Tailwind CSS
- Redux Toolkit

### Backend
- Next.js API Routes
- Prisma ORM

### Database
- PostgreSQL (via Prisma)

### Authentication
- Clerk Authentication
